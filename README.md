# Duplicate Question Detection

Identify Quora question pairs that have the same intent.

## Approach

- Text and similarity feature engineering
- Pretrained word embeddings and spaCy processing
- Gradient boosting with LightGBM and XGBoost

## Results

Accuracy between about 0.71 and 0.76 in the saved notebook output.
